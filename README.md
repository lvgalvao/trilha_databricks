# 🚀 Trilha de Databricks - Jornada de Dados

Bem-vindo(a) à **Trilha de Databricks da Jornada de Dados**! Este repositório contém todos os materiais práticos, exercícios e recursos necessários para você dominar a plataforma Databricks e implementar soluções completas de Data Warehouse seguindo o padrão Bronze → Silver → Gold.

---

## 🎯 Início Rápido

**Novo na trilha?** Siga estes passos:

1. ✅ **Assista à aula de boas-vindas** (link abaixo)
2. 📚 **Acesse a Aula 01** na plataforma online para configurar seu ambiente
3. 💻 **Clone este repositório** para ter acesso aos materiais práticos
4. 📖 **Siga a ordem recomendada** de estudo (veja seção abaixo)

### 📋 Pré-requisitos

Antes de começar, certifique-se de ter:

- ✅ Acesso a um workspace Databricks (Free Edition ou Trial)
- ✅ Conhecimento básico de SQL e Python
- ✅ Familiaridade com conceitos de ETL/ELT e modelagem de dados
- ✅ Git instalado (para clonar o repositório)

## 📖 Como Usar Este Repositório

### 📝 O Que Você Encontra em Cada Aula

- **📓 Notebooks**: Materiais práticos e exercícios para execução no Databricks
- **💻 Scripts SQL/Python**: Códigos reutilizáveis para ingestão e transformação
- **📊 Dados de exemplo**: Arquivos CSV, Parquet e outros formatos para prática
- **📚 Documentação**: READMEs específicos com objetivos, pré-requisitos e exemplos práticos

### 🎯 Ordem Recomendada de Estudo

Para aproveitar ao máximo a trilha, siga esta sequência:

1. **Aula 01** → Configure seu ambiente Databricks e entenda os conceitos fundamentais
2. **Aula 02** → Aprofunde-se nos recursos básicos da plataforma
3. **Aula 03** → Aprenda sobre governança com Unity Catalog
4. **Aula 04** → Pratique ingestão de dados com Lakeflow Connect
5. **Aula 05** → Automatize workflows com Lakeflow Jobs
6. **Workshop 01** → Implemente um Data Warehouse completo do zero
7. **Aula 06** → Domine pipelines declarativas com DLT
8. **Aulas 07-16** → Continue avançando com Spark, Delta Lake e tópicos avançados

### 💡 Dicas para Sucesso

- ✅ **Assista às aulas primeiro** antes de executar os notebooks
- ✅ **Leia os READMEs** de cada pasta de aula para entender o contexto
- ✅ **Execute os exercícios** no seu workspace Databricks
- ✅ **Participe dos workshops ao vivo** para tirar dúvidas
- ✅ **Experimente e adapte** os códigos para seus próprios projetos
